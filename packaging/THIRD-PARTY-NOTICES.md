# Windows download licenses

Flow's own code is available under the MIT license in LICENSE. The Windows
download includes the following speech and media software.

| Component | License information |
| --- | --- |
| Piper and its eSpeak NG speech components | Piper is GPL-3.0-or-later. Its wheel includes eSpeak NG data and bridge, Apache-licensed g2pW code and MIT-licensed Hebrew processing code. |
| edge-tts | LGPLv3, with an MIT-licensed subtitle module. |
| PyAV and FFmpeg | PyAV is BSD-3-Clause. Its Windows wheel supplies FFmpeg shared libraries and external codec libraries, including GPL-licensed x264 and x265. |
| IBM Plex fonts | SIL Open Font License. The text accompanies the fonts under _internal/flow/assets/fonts. |

The licenses folder contains notices copied from the installed distributions.
See THIRD-PARTY-SOURCES.md for the corresponding sources and build information.
Voice and recognition model weights downloaded separately have their own licenses.
