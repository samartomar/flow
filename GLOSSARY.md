# Flow

Flow is push-to-talk voice input for the desktop: what you say becomes text in the window you are working in, written as it is or rewritten for where it is going, and questions go to the agent CLI you already use.

## Jobs

**Dictate**:
Saying words and having them land as you said them, tidied only by Flow's own spoken edits.
_Avoid_: Type mode (as a name for the job), transcribe

**Refine**:
Saying words and having them land rewritten in a chosen style by the agent CLI.
_Avoid_: Polish (as a name for the job), rewrite mode

**Ask**:
Putting a question to the agent CLI and getting an answer on Flow's answer card, as a conversation that remembers earlier turns.
_Avoid_: Converse, chat, query

## Where words go

**Target window**:
The window that receives what Flow lands: the window you were typing in, or the pinned window when there is one.
_Avoid_: Destination, focus, client

**Pinned window**:
A window you have fixed as the target window, so everything Flow lands goes there wherever you are working.
_Avoid_: Pinned screen, locked window

**Landing**:
Flow putting text into the target window, as a paste with no Enter.
_Avoid_: Send, insert, deliver

## How Refine writes

**Piece**:
The one text a Refine builds over one or more holds, rewritten as a whole each time and replacing what it landed before, until you edit it yourself, change window or style, or say "done".
_Avoid_: Draft (the words held before they land), session, thread

**Style**:
A named way Refine writes, with instructions you can read and change, such as Prompt for a coding agent, Email to send, Chat message, Tidy up, or one you made.
_Avoid_: Kind, refinement prompt, template, mode

## How Ask answers

**Lens**:
A named viewpoint Ask answers from, with instructions you can read and change, such as an architecture lens or a business lens.
_Avoid_: Persona, role, perspective, mode
